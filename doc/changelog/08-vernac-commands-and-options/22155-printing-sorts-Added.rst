- **Added:**
  ``Printing Sorts`` flag, which displays sort variables in sorts
  (e.g. ``Univ@{s ; _}``) and the universe instances that carry sort
  qualities (e.g. ``f@{Prop ; _}``), with universe levels replaced by
  ``_``, making the sort structure visible without exposing universe
  level names
  (`#22155 <https://github.com/rocq-prover/rocq/pull/22155>`_,
  fixes `#22153 <https://github.com/rocq-prover/rocq/issues/22153>`_,
  by Jason Gross).
